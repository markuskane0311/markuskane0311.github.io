Privacy Policy: personal-audio-index

Effective: November 22, 2026

Who uses it. One adult, for personal, non-commercial, private use. There are no other users, no accounts, no ads, no analytics, and no tracking.

What is stored (data minimization). For each public post in the fixed list of audio communities that contains a link to an audio host (for example soundgasm.net), only these fields are stored:

  • post ID, subreddit name, post title, and permalink
  • author username and post flair text
  • post creation time
  • the audio-host link(s) found in the post

What is never stored. Post bodies or self-text, comments, images, audio or other media, votes, scores, user profiles, IP addresses, private messages, and data about anyone who views the app. Post text is read in memory only to find audio links, then discarded.

Where it is kept. A private Supabase database (free tier) that only the owner can access with a secret key, plus the owner's personal search index on his own computer. Nothing is public.

Sharing. None. The data is not sold, shared, published, or given to third parties.

Deletion. Stored posts are re-checked on Reddit at least every 6 hours for 30 days. If a post was deleted by its author, removed by moderators or Reddit, or can no longer be retrieved, its row is deleted and its entry is removed from the owner's personal index. Rows can also be deleted on request: email the contact below with the post link and it will be removed within 7 days. If the app is uninstalled, all stored data is deleted.

Retention. Data is kept only while the app is in personal use.
